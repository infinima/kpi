## Правила кеша и сессии

Принят TanStack Query v5. Автоповторы, refetch по фокусу и восстановлению сети отключены, чтобы перенос не добавлял скрытых повторных HTTP-операций. Активные данные обновляются после успешных предметных мутаций. Смена токена очищает кеш и пересоздаёт содержимое маршрутов, сохраняя BrowserRouter и его историю.

Снимок пользователя/прав принадлежит сессии; профиль формы загружается отдельно и после сохранения обновляет сессию. Кеш рассылок содержит список и согласованные детали, которые обновляются вместе. Realtime-снимки принадлежат конкретным подключениям и не дублируются в HTTP-кеше.

Подключения получают leagueId/type/token явно. Переключение контекста закрывает старый socket и убирает обработчики; поздние callbacks игнорируются. На reconnect таблица запрашивается заново. Команды не буферизуются для отправки после отключения. PDF и изображения освобождают object URL; камера и анимационные кадры очищаются при остановке сканера.

## Удаление старого кода и зависимости

Удалялись только модули, недостижимые от точки входа с учётом статических и строковых ленивых импортов, либо заменённые перенесёнными реализациями. Удалены старые TablePage/UserPage, строки старых игровых таблиц, неработающие старые layout/menu/modal-модули, DataTable и связанные старые конфиги. Исходный список кандидатов сохранён отдельно.

Убраны неиспользуемые @react-pdf/renderer, file-saver, jszip, react-telegram-login, прямая зависимость pdfjs-dist и @types/file-saver. react-pdf продолжает использовать собственную зависимость pdfjs-dist. Добавлены TanStack Query и типы qrcode.

Установка управляется корневым npm-workspace и package-lock.json; устаревший отдельный frontend/package-lock.json удалён. Локальное объявление типов react-easy-crop сохранено из-за несовместимости установленных типов компонента; оно дополнено используемым objectFit.

## Автоматическая проверка

Запуск из корня: `npm --prefix frontend run check`.

- Границы импортов: проходят для app/pages/entities/shared и представлений/транспорта.
- TypeScript: проходит; исходные 50 диагностик устранены. Включены проверки неиспользуемых объявлений и параметров.
- Клиентские тесты: 64 теста проходят — HTTP и сессия, кеш/дедупликация/инвалидация/очистка, DTO и тела запросов, формы, права, QR, таблицы, подтверждения, socket lifecycle и совместимость маршрутов.
- Production build: проходит; крупные экраны разделены на ленивые chunks. Начальный JS — 276.92 kB (gzip 89.31 kB), против исходного общего JS 1282.14 kB (gzip 381.32 kB). Самый крупный ленивый chunk показа — 435.03 kB; предупреждения о chunk >500 kB больше нет. CSS — 53.92 kB.
- `git diff --check`: проходит; backend-файлы не изменены.

Осталось исходное предупреждение об устаревшей базе Browserslist; обновление этой базы не включалось в архитектурный перенос.

## Ограничения и выпуск

По решению пользователя выполнялись только сборка, типы и клиентские тесты. Ручные сценарии и реальные HTTP/Socket.IO-подключения не проверялись. Клиентские фикстуры и fake-sockets подтверждают преобразования и жизненный цикл, но не заменяют интеграционную проверку сервера.

Существующие заглушки accounts/tables/fudzi-presentation оставлены заглушками. Ветка галереи площадки по-прежнему не имеет зарегистрированного /photos-маршрута: новый сценарий не добавлялся без отдельного продуктового решения. Внешний PDF worker react-pdf продолжает загружаться прежним способом.

Готовность к публикации не заявляется: перед выпуском нужны совместимость с целевым API, согласованные ручные проверки и отдельное решение о размещении/деплое.
